# PM 项目接入技能

两个通用流程技能，用于规划新项目接入独立 PM，以及已有项目的渐进式集成。

| 技能 | 用途 |
| --- | --- |
| `pm-new-project-onboarding` | 新项目的角色配置、审批、隔离演练、独立验收与恢复 |
| `pm-existing-project-integration` | 已有项目的只读盘点、历史映射、影子运行、单写移交、试点与回退 |

每个技能包含 `SKILL.md`、`references/PLAN.md` 和 `assets/checklist.md`。本仓库仅发布这六份通用文档，以及本说明和忽略规则。

## 状态

这是可供审阅和手动接入的流程模板；发布不代表 PM 运行时已经实现、安装、接线、验收或激活。

已进行人工内容审查与本地敏感信息模式扫描。专用 `skills-security-check` 不可用，未执行该专用 audit；这些检查不构成安全认证，也不保证不存在所有风险。尚未安装到任何技能宿主或业务项目。

## 手动安装

1. 获取仓库后，先阅读目标技能的三份文档，确认内容和权限边界适合你的项目。
2. 在所用技能宿主的官方说明中确认它实际支持的用户级或项目级 skills 目录，不假设通用安装路径。
3. 将 `skills/pm-new-project-onboarding/` 或 `skills/pm-existing-project-integration/` 整个目录复制到已确认的目录，保留其 `references/` 和 `assets/` 子目录；若同名目录已存在，先审阅差异并备份，不直接覆盖。
4. 按宿主要求刷新或重新加载，再核实是否成功识别。复制文件不等于功能已启用或运行时已安装。

## 安全边界

技能文档只提供流程建议，不授予执行权限。实际模型入口、审批主体、角色隔离、单写控制和恢复机制必须现场核实；未知或缺失能力应明确记录并阻塞受影响操作。

沿用用户明确授权的范围。生产发布、账户修改、服务重启、数据迁移和其他新增或不可逆动作应获得对应授权。不要在任务卡、报告、提交或公开仓库中写入凭据实值、私钥、个人隐私或内部地址。

本仓库不包含独立 PM 运行时、内部报告、旧证据、ZIP 包、本地 memory 或凭据。它没有指定许可证；公开可见不等于已授予开源再分发许可。
